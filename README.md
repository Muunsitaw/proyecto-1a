# proyecto integrador de primer semestre
Solución en Java de dos problemas, documentada con una página web y trabajada en equipo con ramas y Pull Request.

## Resumen
Se desarollo un único programa en Java con un menú de dos opciones. Cada opción uno de los dos problemas asignados: la primera opción resuelve el problema 1 y la segunda opcion resuelve el problema 2. El programa cuenta con su código fuente comentado y diez casos de prueba manuales por problema, con un cálculo previo y comparación de resultados. La pagina web explica el objetivo, la problemática, la metodología, el analisis de resultados y la conclusión.
